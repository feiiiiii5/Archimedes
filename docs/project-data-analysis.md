# Save and resume a project analysis

Open **Analyze my data** in a project workspace, then choose a CSV/TSV file or an
example dataset. Statistics and plots run locally. Use **Save analysis to
project** to retain the complete original file, plot settings, descriptive
statistics, question and current SVG chart.

Choose an entry in **Saved analyses** and click **Open saved analysis** to resume
it after reopening the project. Saving updates that entry; choosing a new file
or example begins a new entry. Unsaved working drafts remain separate for each
project workspace while the app is open.

**Continue in chat** prepares a discussion draft with statistics and up to five
sample rows. **Continue with original CSV / TSV** also saves the complete file
and attaches its workspace path, so workspace tools can read it. The complete
dataset is not copied into the message. Review the draft before sending it.

A saved analysis retains its associated discussion. Completing that association
keeps the saved source, settings and chart together, even if another dataset or
data folder is selected while the discussion opens.
